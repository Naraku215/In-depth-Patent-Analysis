# 专利解析 Agent

把一件专利整理成可读、可查、可复用的三种产物：结构/流程视图、关键原理图、深度解析。

## 适用场景

适合有明确技术内容的专利：设备、装置、系统、工艺、材料、参数方法，以及“方法里包含一套具体装置”的专利。

没有可确定空间结构的纯方法、纯配方、纯参数专利，不要硬造机器。可以把解剖台改做流程图、接口图或状态/参数图；图鉴没有可确定形状或行为时直接省略。

## 怎么用

1. 在本机打开这个文件夹，使用能读 `AGENTS.md`、能执行命令的 agent 客户端。
2. 把一件专利放进 `patents/`：

```text
patents/
└── 任意名字/
    ├── full.md      ← 专利全文（含权利要求书）
    └── images/      ← full.md 引用的附图
```

3. 在对话里说：

> 解析一下 US 10,150,093 B2

产物会生成在 `out/<id>/index.html`。

## 产物与阅读顺序

| 产物 | 作用 | 什么时候有 |
|---|---|---|
| **专利解剖台** | 入口：快速建立结构、流程或接口的空间直觉 | 必有；形式不固定 |
| **专利结构动态演算图鉴** | 定稿：用少量图把关键原理或数量关系讲透 | 视情况；没有可确定形状或行为时不做 |
| **深度解析** | 通读：解释它是什么、怎么做、保护什么、没证明什么 | 必有 |

建议按这个顺序看：

1. **解剖台**：先建立整体认识。可以是爆炸、半剖、侧视、局部放大、流程图、接口图或状态对比。
2. **图鉴**：如果存在，用它确认关键结构/原理和读数关系。一张图只回答一个问题；图上出现的数字必须能追回说明书，模型算出的必须标明。
3. **深度解析**：最后读权项、实施例、数据与证据边界。

三者不是同一件事的三种画法：解剖台负责探索，图鉴负责定稿，文档负责通读。

## 生成与验收

```bash
node bin/patent.mjs extract <id>   # 抽取 facts.json
node bin/patent.mjs build <id>     # 生成解剖台、图鉴、文档
node bin/patent.mjs verify <id>    # 线端、渲染、语义标号一致性
node bin/patent.mjs package <id>   # 生成 out/<id>/index.html
```

自动抽取之后需要人工确认时，把修正写进 `work/<id>/facts.overrides.json`，不要直接依赖手工改 `facts.json`。覆盖层会在下一次 `extract` 时重新应用。

美国专利常见的“名词 + 数字”标号会进入 `facts.referenceSigns` 和 `facts.figureSigns`；这些是候选，必须结合附图确认后再用于解剖台。

## 质量规则

- **一张图说一件事**：每个视图只回答一个明确问题。
- **数字可追**：带单位的数字要么回到说明书，要么明确标成模型值/读数说明。
- **标号对得上**：3D 视图里的数字标签必须与右侧标号表一致。
- **不硬造结构**：专利没画、没写的零件不要为了“完整”补进去；通用件和示意件必须标明。
- **说清证据边界**：专利没证明的产率、寿命、能效、流场，不要替它证明。

## 目录

```text
AGENTS.md          agent 作业手册
README.md          本文件
bin/patent.mjs     命令行
lib/               抽取、审计、渲染、打包
prompts/           图鉴与解剖台的写法
templates/         解剖台、图脚本、文档骨架
skills/anatomy/    vendored anatomy 制图技能
patents/           输入：一件一个文件夹
work/<id>/         工作区：facts、图脚本、站点、doc、notes
out/<id>/          交付：index.html + 产物文件
```

`work/` 和 `out/` 都在 `.gitignore` 里。`work/` 可以重建，`out/` 可以整个文件夹拷走。

## 环境与许可

- Node.js ≥ 20.10；`verify` 与缩略图需要 Chrome / Chromium。
- 无第三方依赖，不用 `npm install`。
- MIT。`skills/anatomy/` 为 [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) 的 vendored 副本，遵循原 MIT 许可。
