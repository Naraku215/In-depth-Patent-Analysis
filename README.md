# 专利解析 Agent

把一个专利文件夹，变成**一个可以点着看的 `index.html`**：三维解剖台 + 深度解读是固定两件，专利里有实体结构时再加一份工程图鉴。

用于绿氢 / 燃料电池这类**系统、装置、流程、反应器**专利——目标是让人在半小时内看懂一件本来要读两天的专利。

---

## 用起来就三步

**1. 克隆到本地，用你的 agent 客户端打开这个文件夹**

Codex、Claude Code、Work Buddy、Cursor 之类，只要是能读 `AGENTS.md`、能跑命令的客户端都行。

**2. 把你的专利放进去**

```
patents/
└── 你的专利名/           ← 目录名随意
    ├── full.md            ← 专利全文（要含权利要求书）
    └── images/            ← full.md 里 ![](images/xxx.jpg) 引用的图
```

**3. 在对话里说一句**

> 解析一下 US 10,150,093 B2

它会自己跑：读专利 → 画图 → 建解剖台 → 写文档 → 自检。跑完给你一个 `out/<id>/index.html`，双击就开。

---

## 会得到什么

| 产出 | 有无 | 是什么 |
|---|---|---|
| **专利解剖台** | **必有** | 按专利尺寸搭的三维模型，可旋转、爆炸分解、剖切 |
| **深度解析** | **必有** | 固定模板：结论、结构、原理、工艺、数据、权项、证据边界、假设与简化 |
| **专利结构动态演算图鉴** | 有实体结构才有 | anatomy 等轴测工程图，指针一动读数就变 |

纯方法、纯配方、纯参数型专利撑不起一台机器，**就不画图鉴**——这时候是两件：解剖台 + 文档。硬画一张似是而非的机器图，比不画更糟。

---

## 它凭什么可信

这个项目唯一的硬要求是：**不能把专利理解歪**。

- 产出里每个数字、每个部件标号、每处「权项 N」、每处段号，都要能在 `full.md` 里查到；
- 查不到的，必须写明「这是模型值 / 这是假设」，并说明依据；
- 假设必须符合学科常识（泵就是泵、换热器就是换热器），不能为了画面好看编结构；
- 专利没证明的事，写进「证据边界」，不替它圆。

这些不是事后检查，是**生成时的门禁**：`build` 跑完自动校验，`package` 之前再校验一次，**不过就不出包**。附属的 `test/run.mjs` 是这套门禁自己的自检。

## 目录

```
AGENTS.md          agent 作业手册（读这个就知道怎么干活）
CLAUDE.md / SKILL.md   给不同客户端用的入口指针
patents/           你把专利放这里
out/               解析结果（gitignored）
work/              中间产物（gitignored）
bin/patent.mjs     命令行
lib/               解析 / 校验 / 渲染 / 打包
prompts/           各阶段提示词
templates/         解剖台站点、图脚本、文档模板
skills/anatomy/    vendored 的 anatomy 制图技能（MIT）
examples/          一个虚构专利的完整样例
docs/              方法论与质检清单（维护者看）
test/run.mjs       自检
```
