# 质检清单

从一次**真实的返工**里蒸馏出来的：那批解析交付前查出 14 项问题，11 项是实质数值错误。
每一条都对应一个现在能机检的检查项。

---

## 一、数字（最高危）

- [ ] **区间端点是不是串了？** 例：Co 负载写成 `5–60 wt%`，原文是 `5–50`；那个 60% 出现在 CO₂ 浓度、孔隙率、CO 转化率三处，都不是这个指标。
  → `E-NUM-UNTRACED` 会报，但**串值可能刚好都能检索到**，要人工核对上下文。
- [ ] **是不是把图读成了数？** 例：一张五点 PMMA 表，实际正文只给两个端点，中间 12 个数是"看着图补的"。
  → 图里的读数只能写趋势，不能写成表格数字。
- [ ] **有没有自造约束？** 例：二次狭缝"宽度为通道间隙的 10–70%"，原文只有 `smaller dimensions`。
  → 为了让图好看而编具体比例，是最隐蔽的错误。
- [ ] **单位对吗？** mm / µm / nm 差三个数量级；wt% / mol% / vol% 不是一回事。
- [ ] **换算写清了吗？** 277 mm − 2×50 mm = 177 mm，这类换算要么写出算式，要么标"换算"。

## 二、标号

- [ ] 每个标号在 `facts.numerals` 里能查到。
- [ ] 没有"惯例性补号"：原文标号 1、3、4、5、6 时，**不要**补一个 2 占位。
- [ ] 一个标号只指一个部件（原文自己重号时要注明）。
- [ ] 正文里说"标号 N"，图里/表里也是 N。

## 三、权项

- [ ] 「权项 N」的 N ≤ 总数。
- [ ] 引用的内容确实是第 N 条的意思，不是第 N−1 条的。
- [ ] 独权与从权的层级描述正确（"权项 1 的从权"不能写成"权项 1 包含"）。
- [ ] 如果 `full.md` 里没有权利要求书，**必须标注"未获取，以下为反推"**。

## 四、段号

- [ ] `[0013]` 这样的段号在原文里存在。
- [ ] 段号指向的内容与引用处一致（这一段讲的是不是这件事）。

## 五、文字完整性

- [ ] 没有重复汉字损坏（`填填`、`道道`、`利利`、`一一段`）。
- [ ] 没有占位符残留（`{{…}}`、`TODO`、`待补`、`…` 结尾的句子）。
- [ ] 中英文混排时没有半角/全角错乱。

## 六、图

- [ ] 每张图有底座、有支撑关系、无悬空零件。
- [ ] `verify`：`悬空线端 0`、`console clean`。
- [ ] 放大到 4× 仍有真实细节（不是纯色块）。
- [ ] 图里的读数会随指针变化，且能算得出来。
- [ ] 说明里写清了"哪些是专利的、哪些是示意的"。

## 七、解剖台

- [ ] ≥ 3 个视图。
- [ ] 每个视图都能爆炸。
- [ ] 每个视图都有 `A.notes` 解读与部件表。
- [ ] 拖动旋转不卡、剖切正确、`statViews` 不是 `—`。

## 八、文档

- [ ] 九节齐全（0–8 + 附录）。
- [ ] 附录里的每个数在正文出现过，反之亦然。
- [ ] 证据边界 ≥ 3 条，且没有替专利圆场。
- [ ] 分析段落有标记（"这是推断""说明书未明说"）。
- [ ] 没有"可能/也许"式的空话。

## 九、交付

- [ ] `out/<id>/` 里三件产出 + 审计报告齐全。
- [ ] 双击任意 html 能打开，无控制台报错。
- [ ] `index.html` 链接全部可点。
- [ ] 交付话术里有一句"已知边界"。

---

## 一句话总结

> **能被检索到的才写，写不出处的就标出来。**

这套系统里所有检查，最终都落在这句话上。
