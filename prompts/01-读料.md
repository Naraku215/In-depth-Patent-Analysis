# 阶段 1 · 抽取与读料

## 命令

```bash
node bin/patent.mjs extract <id>
node bin/patent.mjs facts <id>
```

`facts.json` 是确定性产出，不用你写。但**你必须读它**，否则后面每一步都会编。

## 你要产出什么

在 `work/<id>/notes.md` 写一份「读料笔记」，四块：

### 1. 它是什么
- 公开号、主题、权利人、类型（装置 / 方法 / 构件 / 用途）
- **一句话**：这件专利解决什么问题，用什么办法

### 2. 结构骨架
- 独立权项的元件清单（a/b/c…），逐条抄原文，不要转述
- 这些元件之间怎么装在一起（谁在谁上、谁包谁）

### 3. 数字
从 `facts.numbers` 里挑出**定义性**的数字（不是随便一个数）：尺寸、比例、温度、压力、时长、载量。
每个数字记三样：值 · 单位 · 出处（权项号或 `[00xx]`）。

### 4. 证据边界
专利**没有**证明什么。常见几类：
- 只有短时数据，没有寿命数据
- 只有定性描述，没有表征（SEM/XPS/称重）
- 只说"可以"，没有给实施例
- 前后数值自相矛盾（要原样记下来，不要替它圆）

## 门禁

- 每条结论都能指回权项号或段号
- 证据边界至少 2 条
- 看到矛盾就记矛盾，不许"合理化"

## 审图

`patents/<dir>/images/` 里的图要亲眼看。判断：
- 这是剖视图、爆炸图还是流程图？
- 图里的标号怎么分布的？
- 哪张图最适合做成解剖台的主视图？

把结论写进笔记第 2 块。
