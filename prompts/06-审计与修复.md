# 阶段 6 · 审计与修复

## 跑

```bash
node bin/patent.mjs audit <id>
```

退出码：`0` 通过 / `2` 有错误 / `1` 命令本身失败。

## 六类错误与修法

### `E-NUM-UNTRACED` — 数字无出处
审计把产出里每个带单位或小数的数字，拿去专利全文里检索。找不到、且**同一段落里没有免责标记**的，就是这一条。

修法二选一：
1. **改成原文数字**（首选）。打开 `facts.claims` / `facts.paragraphs` 找到真实值。
2. **标注为模型值**。在该段末尾加一句：
   > 读数说明：上表中的 0.62 mm 与 −38% 是按两片试样的内弓量算出的模型值，专利未给具体数值。

允许的免责标记（配置在 `patent-anatomy.config.json`）：
`读数说明` `画法说明` `模型` `示意值` `本图取` `非专利` `换算`

> ⚠️ 不要把数字删掉来过关。删掉的必须本来就是"没出处的编造"；有出处的要补出处。

### `E-NUMERAL-UNKNOWN` — 标号不存在
产出里出现 `['12', '…']` 或 `` | `12` | … `` 这种部件表，但专利原文没有 12 号。
修法：换成原文真实标号，或改成描述性名称（不带数字）。

### `E-CLAIM` — 权项越界
「权项 12」但专利只有 7 项。修法：改编号，或删掉这个引用。

### `E-PARA-REF` — 段号不存在
「[0013]」但原文没有这一段。修法：改段号。

### `E-CORRUPTION` — 重复汉字
批量替换留下的损坏（`填填` `道道` `利利`）。修法：逐个改成正确的字。

### `W-LINK` — 失效链接
HTML 里有指向不存在文件的相对链接。修法：删链接或补文件。

## 修复循环

```
audit → 看 errors → 修一个 → 重跑 audit → 直到 exit 0 且 score 100
```

**不要一次改十处再跑**——改一处跑一次，否则分不清是谁修好的。

## 最后一次全量复核

审计通过后，还要你自己看一遍（机器查不出来的）：

- [ ] 三件产出都能双击打开、不报错
- [ ] 图鉴里每张图放大到 4× 仍能看到真实细节（不是模糊的色块）
- [ ] 解剖台至少 3 个视图，爆炸拉杆每层都动
- [ ] 文档里没有"待补""TODO""…"这类占位
- [ ] 附录表与正文数字一致
- [ ] 证据边界那节，你自己读一遍：有没有替专利圆场

## 交付前

```bash
node bin/patent.mjs package <id>
```
然后向用户报告三件事：
1. 三件产出的路径
2. 审计评分与"已修正 N 项"
3. 一句话的已知边界（如"权利要求书未包含在 full.md 中，第 6 节为反推"）
