# 阶段 3 · 图鉴（可选）

## 先判断做不做

**专利里有没有可指的实体结构？**

- 有——反应器、电堆、测试台、装配体、管路系统：做。
- 没有——纯方法、配方、参数、控制律、纯流程：**跳过这一阶段**，出解剖台 + 文档两件。

判断句：**能不能指着专利里的某个部件说"这是它的结构"？**
不能就别画。画出一台拼凑的机器，比不画更糟。

---

## 先读技能

**必须先 `skill("anatomy")` 加载完整技能说明**，再动笔。技能在 `skills/anatomy/SKILL.md`，kit 在 `skills/anatomy/kit/iso-kit.mjs`。

技能的核心不是"画图"，是：**用一个真实存在的机器，把专利的原理演出来**。
不是画箭头和标签，是造一台机器，让它的运转本身就是解释。

## 文件

```
work/<id>/build/
├── shared.mjs       ← 已铺好，别删
├── fig-01.mjs       ← 你的第一张图（从模板改）
├── fig-02.mjs       ← 第二张
└── atlas.mjs        ← 编页，改顶部 FIGS 数组即可
```

## 每张图的要求

### 选材：一张图只讲一件事
从这三类里选：
1. **构件级的物理行为**（受压、膨胀、折弯、流动）——做成一台试验台/压机；
2. **装配关系**（层序、密封、连接）——做成爆炸视图；
3. **工艺流程**（多级、循环、再生）——做成一台流程装置。

不要在一张图里塞两件事。2–4 张图，覆盖主要面即可。

### 尺寸必须来自专利
`fig-01.mjs` 顶部有一块 `/* ---- 1. 尺寸 ---- */`，每个常量后面写注释标明出处：
```js
const CH_W = 1.0;      // 通道宽 [0018]
const CH_H = 6.5;      // 波高 [0032]
```
图上没有出处的尺寸只能是三种：底座厚度、装饰圆角、画布间距——这三类不写注释。

### 必须有的东西
- **底座**：一台放在工作台上的机器，脚下要有脚/垫
- **支撑关系**：每个零件都坐在别的零件上，没有悬空
- **真实读数**：`readout` 里的数字由 `script` 里的模型算出来，指针一动就变
- **图例**：3 条 `keys`，分别标「lit / raised / dim」三种状态
- **说明**：`caption` 里必须写清这台装置哪部分来自专利、哪部分是示意

### 读数纪律
图里的读数分两类，**必须分开写**：
- 专利给了的：直接用，caption 里标出处；
- 专利没给的（模型算的）：caption 里写「读数说明：…为该模型算出的值，专利未给具体数值」。
  注意 anatomy 的 `plateHtml` 会转义 HTML，所以**不要用标签**，直接写「读数说明：…」。

### 禁止
- 悬空线头（`verify` 会查）
- 没有支撑的浮空零件
- 图里写大段文字（只允许一个极小的 FaceText）
- 用颜色表达含义（颜色只用于材质，不用于编码信息）

## 编页

改 `atlas.mjs` 顶部：
```js
const FIGS = [
  { file: "fig-01.mjs", name: "fig01" },
  { file: "fig-02.mjs", name: "fig02" },
];
```
以及 `INTRO` 里的 `{{KICKER}}` `{{H1}}` `{{LEDE}}`。
